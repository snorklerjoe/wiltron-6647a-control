Wiltron 6647A GPIB Programming Guide Summary
1. Instrument Communication Interface

The Wiltron 6647A sweep generator functions as both a listener and a talker on the GPIB. It provides complete front-panel-control operation over the bus when equipped with Option 3.  
IEEE 488 Subset Capabilities

The instrument supports the following IEEE 488 interface bus subset functions:  

    AH1: Acceptor Handshake (Complete Capability)   

    SH1: Source Handshake (Complete Capability)   

    T6: Talker (Basic Talker, Serial Poll, Unaddressed if MLA, No Talk Only)   

    L4: Listener (Basic Listener, Unaddressed if MTA, No Listen Only)   

    SR1: Service Request (Complete Capability)   

    RL1: Remote/Local (Complete Capability)   

    PP1: Parallel Poll (Complete Capability)   

    DC1: Device Clear (Complete Capability)   

    DT1: Device Trigger (Complete Capability)   

    C0, TE0, LE0: No Controller or Address Extension Capabilities   

Message Syntax and Error Handling

Communication is achieved via device-dependent commands (bus commands) and IEEE 488 Bus Messages.  

    Parameter Syntax: Values are written exactly as they are entered from the keyboard (integers or decimal numbers) and must be followed by a suitable terminator (e.g., GH, MH, SEC).  

    Command Chaining: Multiple commands can be sent in a single string (e.g., "DF0 F02GH DLF10MH AUT" ).  

    Invalid-Parameter Errors: Attempting to enter out-of-bounds parameters, failing to use proper terminators, or setting a start frequency higher than a stop frequency will cause the front panel indicators to flash.  

    Syntax Errors: Errors in command formulation (e.g., typing EXTTFS instead of EXTTRS) will cause the generator to ignore all subsequent portions of the command statement. The instrument will ignore all commands until it receives an Unlisten (UNL) command or is addressed to talk.  

2. Supported IEEE 488 Bus Messages

In addition to device-specific commands, the instrument recognizes standard bus messages:  
Bus Message	Function
Device Clear (DC/SDC)	

Aborts GPIB activities and resets step sweep, SRQ modes, and event flags to default states.
Go to Local (GTL)	

Returns the sweep generator to local (front panel) control.
Group Execute Trigger (GET)	

Depending on configuration, triggers a new sweep, increments/decrements a selected parameter, or steps the digital sweep.
Interface Clear (IFC)	

Stops the interface from listening or talking without clearing front panel controls.
Local Lockout (LLO)	

Prevents the front panel "RETURN TO LOCAL" button or the RL command from returning the unit to local control.
Remote Enable (REM)	

Places the generator under remote control when addressed to listen.
Serial Poll (SPE/SPD)	

Causes the generator to output a status byte indicating if it requested service and why.
Parallel Poll (PPC/PPE/PPU/PPD)	

Configures the instrument to respond to parallel polls by asserting an assigned data line to indicate its SRQ status.

B. Digital Step Sweep Commands
Command	Name	Function
STP	Step Sweep	

Selects the Step Sweep mode of operation (4096 discrete points).
STSXXXXE	Step Select	

Selects increment point (0 to 4095) where the sweep starts. STS0E or STSE for zero.
SIZXXXXE	Increment Size	

Sets the step count (1 to 4 digits) for incrementing via the N, UP, or DN commands. Decimals are ignored.
N	Go to Next Step	

Increments the Step Sweep by the amount programmed in the SIZ command.
